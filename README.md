# Independent QA Testing Project — SauceDemo

## 1. Project Overview
This project documents an independent manual testing exercise conducted on SauceDemo, a demo e-commerce web application. The objective is to practice test case design, manual test execution, result documentation, and exploratory testing.

## 2. Testing Scope
- Login with valid and invalid credentials
- Required-field validation
- Locked-account behavior
- Exploratory testing of product listing and product detail pages
- Preliminary observations of shopping cart interactions and UI consistency

## 3. Testing Approach
Manual testing was performed by entering test data, executing user actions, comparing actual results with expected results, and recording the outcome.

## 4. Test Artifacts
- `QA_Testing_ECommerce_Portfolio.xlsx` — test cases, test execution results, and preliminary issue reports
- Screenshots — supporting evidence for selected observations, where available

## 5. Initial Login Test Results
- Test cases executed: 8
- Passed: 8
- Failed: 0

These figures apply only to the recorded login test cases, not to the entire application.

## 6. Preliminary Observations
Exploratory testing with demo accounts revealed possible inconsistencies involving product images and information, product detail navigation, shopping cart interactions, and UI layout. These observations require appropriate verification before being classified as confirmed defects.

## 7. Test Environment
- Application: SauceDemo (demo web application)
- Testing type: Manual functional and exploratory testing
- Browser and operating system: Record the versions used during testing

## 8. Project Limitation
This is an independent practice project conducted on a demo application. Results reflect the observed behavior during the documented test sessions and should not be interpreted as findings from a production application.
