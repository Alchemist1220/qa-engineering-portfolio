# qa-engineering-portfolio
Independent QA testing portfolio for SauceDemo, including manual test cases, test execution results, and exploratory testing observations.

## Testing Scope
- Login with valid and invalid credentials
- Empty-field validation
- Locked-account behavior
- Exploratory testing of product listing and product details
- Preliminary observations of cart interactions and UI consistency

## Testing Artifacts
- `Test_Cases`: structured login test cases
- `Test_Execution`: actual results and execution status
- `Bug_Reports`: documented observations and preliminary defect reports

## Initial Results
- Login test cases executed: 8
- Passed: 8
- Failed: 0
- Additional observations: product information, navigation, cart, and UI behavior

## Project Notes
This is an independent practice project using a demo application. The login results and exploratory observations are documented separately. Additional observations may require further verification before being classified as confirmed defects.
